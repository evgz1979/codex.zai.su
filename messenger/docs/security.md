# Безопасность

## Серверный WhatsApp Web

На этапе тестирования WhatsApp доступен только владельцу: серверный реестр
передаёт признак владельца фабрике runtime. У гостей адаптер не создаётся,
сохранённый флаг подключения не запускает восстановление. Все `whatsapp/*`
методы личной admin-роли закрыты 403, независимо от состояния кнопок интерфейса.

Worker принимает фиксированные команды через приватный Unix socket. URL,
JavaScript, shell и произвольный RPC не доступны через HTTP. Ключ профиля
вычисляет backend из каталога аккаунта; пользователь его не передаёт.
Выбор и получатель проверяются до чтения/отправки. Chromium получает данные
как обычный связанный клиент; в Messenger экспортируются метаданные и история
только выбранных чатов. Чужая занятая сессия не заменяется. QR не входит в общий
status и chat API; после ожидания QR роль и блокировка проверяются повторно.

## Личные аккаунты

Пользователей создаёт только admin владельца. Каждому выделены отдельные Auth,
SQLite, vault, медиакеш, TelegramAdapter и push. HTTP выбирает аккаунт по точному
имени ссылки из серверного реестра; тело запроса не меняет этот выбор. Проверка
чужого cookie или роли не даёт доступ. Cookie гостей дополнительно ограничены
Path `/api/u/username/chat` и `/api/u/username/admin`. Блокировка отзывает обе роли,
push и фоновые задачи; во время передачи вложений доступ проверяется повторно.
После чтения тела защищённого запроса сессия проверяется заново.

Имя на главной публично видно по личной ссылке по заданию владельца. Имя не
является секретом и не заменяет пароль. Панель владельца не выдаёт чужих
переписок или Telegram-реквизитов. Файлы доступны сервисному аккаунту и root VPS.
У каждой PWA отдельные scope и worker; endpoint, badge и открытие чата привязаны
к личному пути. [Подробный сценарий](users.md).

## Две роли

- `admin` управляет Telegram, выбором диалогов и паролями; `/api/admin/*`.
- `chat` читает и отправляет сообщения только разрешённых диалогов; `/api/chat/*`.

Пароли хешируются Argon2id: 19456 KiB, 3 прохода, parallelism 1, случайная соль.
Новые пароли Messenger имеют длину 8–512 символов; границы общие для формы,
API и CLI. Изменение политики не заменяет уже заданные пароли и Telegram 2FA.
Хеши паролей отдельные для каждой роли; ключ веб-сессии включает её роль.
Первоначальное задание идёт через SSH
stdin с готовыми хешами до публикации Caddy. Production отказывается запускаться
без обоих хешей, HTTPS Origin и внешнего каталога данных. Старый scrypt-пароль
локального MVP не используется для публичного входа.

Серверные сессии до 8 часов, токены хранятся как SHA-256 digest только в памяти.
Cookie `__Secure-zai_admin` и `__Secure-zai_chat`: Secure, HttpOnly, SameSite=Strict,
Path соответственно `/api/admin` и `/api/chat`. Подмена имени cookie не меняет роль.
При смене пароля сессии роли отзываются. Выход и вход одной роли не управляют другой.

Пять ошибочных попыток за минуту на аккаунт; одновременные проверки входа
запрещены для всего процесса, чтобы ограничить память Argon2 на VPS 1 vCPU/2 ГБ.
POST требует точный HTTPS Origin и CSRF роли, кроме входа (он защищён Origin).
Host проверяется независимо от X-Forwarded-*. JSON-объекты ограничены 20000 байт; authenticated admin/selection — 200000 байт.

## Telegram и файлы

api_id, api_hash и StringSession сохраняются в AES-256-GCM vault только на сервере,
в `/var/lib/zai-messenger`, вне `/opt/zai-messenger/releases`. Каталог 0700,
файлы 0600, процесс работает отдельным непривилегированным пользователем.
Ключ лежит рядом с шифротекстом: root и владелец сервисного аккаунта имеют доступ;
шифрование не защищает от компрометации этого аккаунта или всего VPS.
Код и 2FA живут только до передачи callback teleproto, на диск не записываются.
API возвращает безопасный этап, configured/connected, ограниченную категорию
TelegramAuthIssue и разрешённые административные метаданные. Исходный message,
request или стек исключения не становится диагностическим ответом. Если известен
срок ограничения Telegram, разрешено только целое retryAfterSeconds в заданных
границах. Незавершённый вход и его категория отказа не записываются в SQLite.

Каталог папок доступен только admin; он содержит названия и общие ID без native
peer и access_hash. Состав папки не расширяет selected_conversations. Предпросмотр
последнего сообщения, полученный Telegram вместе с метаданными GetDialogs,
отбрасывается и не выдаётся админке как история невыбранного диалога.

SQLite-кеш не зашифрован; его права и расположение совпадают с приватными данными.
Невыбранная история не запрашивается, не возвращается и не кешируется. Ранее
выбранная история остаётся после исключения; периодического удаления архива нет.
Приватный каталог не входит в release и не обслуживается HTTP.
По заданию от 2026-11-08 новый личный входящий от человека получает разрешение
до преобразования текста. Старые невыбранные и явно исключённые чаты сохраняют
запрет; боты, группы и каналы автоматически не добавляются. Правило и границы
зафиксированы в [ADR-0008](adr/0008-visible-reads-and-new-contacts.md).

В браузере секретные формы существуют только в admin-компоненте и очищаются
после отправки. У администратора есть разрешение вводить секреты по HTTPS,
но получить сохранённые ключи через API нельзя. localStorage не используется.
По запросу владельца от 2026-11-08 IndexedDB хранит ограниченный кеш просмотренных
сообщений каждого личного адреса. Пароли, CSRF, cookie и Telegram-реквизиты туда
не попадают. Кеш не зашифрован; это данные текущего браузера на устройстве.
Чтение ограничено сроком подтверждённой веб-сессии, максимум восемь часов.
Выход очищает историю, включая выход без сети; при восстановлении связи
отзывается оставшаяся серверная сессия. Другие окна того же аккаунта получают
команду очистки без текстов. HTTP 401, отключение аккаунта, снятие выбора и удаления
очищают доступные локальные данные при следующем соединении. Отзыв на сервере
невозможно узнать без сети: до соединения действует последний подтверждённый срок.
CSP запрещает внешние скрипты и соединения; тексты сообщений выводятся как текст.
Web Push включает сам пользователь после входа в личный чат. Серверная доставка не зависит
от срока веб-сессии; endpoint и VAPID находятся в приватной SQLite. Выход отзывает
устройство, смена пароля чата — все подписки. Push содержит только нейтральный текст
и счётчик, без переписки; endpoint ограничен провайдерами. [Контракт уведомлений](notifications.md).

## Сеть и инфраструктура

Backend всегда слушает 127.0.0.1:4318; наружу он попадает только через существующий
Caddy на msg.zai.su:8443. Caddy остаётся непривилегированным, без capabilities,
с NoNewPrivileges; TLS-ALPN-01 выключен, HTTP-01 идёт через существующий 80→8080.
Guard допускает ровно один proxy на 127.0.0.1:4318 под хостом msg.zai.su.
Другие proxy, bind к 443, новый публичный HTTP-01 backend и DNS-01 запрещены.
VPN, Xray/x-ui, firewall, маршруты и sysctl не изменяются. Сравниваются приватные
снимки PID/start time/hash/firewall до и после установки и отката.

## Просмотр вложений

Метод POST /api/chat/attachment защищён той же chat-сессией, Origin и CSRF.
Сервер проверяет весь маршрут по SQLite до чтения готового файла, во время
загрузки и передачи. Нет произвольного URL, пути или native file location в запросе.
Telegram заново получает ровно указанное сообщение; адаптер проверяет peer и ID.
Файловые references/access_hash используются только внутри backend.

Отдельный фоновый поток предзагружает только выбранные медиа за последние 5 дней
и новые вложения, не расширяя разрешения. При исключении прерываются дальнейшая
загрузка и выдача; ранее сохранённый архив не удаляется. Поток пишет на диск порциями;
размер проверяется и по метаданным, и по фактическим байтам. Незавершённое или
прерванное чтение не становится готовым кешем. Два слота, общий бюджет кеша и
60-секундный срок ограничивают ресурсы. Даже cache hit повторяет проверку прав.

Встроенно разрешены JPEG/PNG/GIF/WebP, MP4/WebM/QuickTime и основные audio MIME.
Растровая сигнатура проверяется также при cache hit, включая миниатюры. PDF
разрешён только после проверки %PDF- и открывается штатным просмотрщиком браузера
в новой вкладке с noopener/noreferrer, без iframe или собственного PDF-движка.
Текст выводится React как текст (до 1 МиБ), HTML/SVG не исполняются и остальные
документы остаются application/octet-stream. Системное меню вызывается только
пользователем через navigator.share при подтверждённом canShare(files); автоматической
передачи другим приложениям нет.
Имена очищаются от пути и управляющих символов. Самоуничтожающиеся вложения и
неподдерживаемые объекты Telegram не скачиваются. Для показа Blob CSP разрешает img/media;
внешние ресурсы не подключаются. Просмотр не использует script, object или iframe.
