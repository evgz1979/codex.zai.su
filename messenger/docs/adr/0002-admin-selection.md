# ADR-0002: отдельная админка и разрешённые диалоги

Статус: принято по заданию владельца. Дата: 2026-11-07.

Дополнение от 2026-11-08: новые личные входящие автоматически получают разрешение,
исключения сохраняются. Правила — [ADR-0008](0008-visible-reads-and-new-contacts.md).

Пользовательский чат остаётся единым интерфейсом без вкладок провайдеров.
Настройки вынесены в отдельный AdminApp по /admin, отдельные API и роль admin.
Роль chat имеет самостоятельный пароль и cookie; размер экрана не даёт прав.

Telegram авторизуется администратором через HTTPS по шагам code/2FA. Хранилище
вынесено за пределы релизов. Пароли Messenger — Argon2id; bootstrap выполняется
перед публикацией. Предыдущее ограничение «только локальный MVP» заменено явным
заданием на публикацию msg.zai.su:8443 через существующий Caddy без изменения VPN.

Выбор диалогов — allowlist в SQLite, пустой по умолчанию. Метаданные доступны
админке, история и отправка — только выбранным ID. Исключение скрывает данные
и прекращает будущую синхронизацию, но не удаляет прежний кеш. SourceAdapter
сохраняется; общий Core, Registry, Selection, UnifiedInbox и AdminService разделены
в одном процессе. Будущих провайдеров и отдельных интерфейсов переписки нет.
