# ADR-0009: закрытые личные аккаунты

Принято по заданию владельца от 2026-11-08. Заменяет однопользовательское
ограничение Messenger; ограничения Codex-клиента и инфраструктуры сохраняются.

Для супруги и нескольких друзей нужны собственные Telegram и переписки.
Владелец задаёт имя в админке и выдаёт персональную ссылку. Главная показывает
имя и принимает только пароль. Публичная регистрация не требуется.

Ссылки имеют вид `/u/username/`, личные настройки — `/u/username/admin`.
HTTP API использует `/api/u/username/chat/*` и `/api/u/username/admin/*`.
Сервисы выбираются по точному серверному реестру; cookie имеют отдельные Path
и проверяются личным экземпляром Auth. ID из тела запроса не выбирает пользователя.

Каждому гостю выделяется отдельный каталог UUID с собственными БД, vault,
TelegramAdapter, ядром, фоновыми задачами и push. Владелец использует прежний
корневой каталог; переноса его данных нет. Реестр имён и блокировок находится
в `accounts.v1` настроек владельца, без секретов гостей. Общий предел —
владелец плюс четыре гостя; одновременно работает одна проверка Argon2.

Управление пользователями доступно только admin владельца. Пользовательский
admin управляет только своим Telegram и паролями. Блокировка отзывает оба входа
и подписки, останавливает задачи, сохраняет архив. У каждой личной установки
PWA отдельные manifest/scope и worker, поэтому переходы и push не смешиваются.

Один процесс и прежний loopback-порт сохраняются. Это разделение данных и прав
в приложении; администратор VPS имеет доступ к файловой системе.
