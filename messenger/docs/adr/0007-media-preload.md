# ADR-0007: миниатюры, автоматический медиакеш и открытие файлов

Статус: принято по уточнению владельца. Дата: 2026-11-08.
Дополняет и частично заменяет [ADR-0006](0006-attachments.md).

## Решение

Текстовая история выбранных диалогов остаётся полной. Отдельный
MediaPreloadService готовит оригиналы и миниатюры за последние 5 дней, затем
все новые вложения. Один последовательный поток использует существующий
AttachmentService и SQLite без очереди внешнего сервиса. Отметка версии и
варианта переживает рестарт; временные ошибки откладываются на минуту.
FloodWait сохраняет паузу медиа на указанный Telegram срок, в том числе после рестарта.
Интерактивное открытие прерывает фон. Исключённые диалоги не попадают в задания.

Миниатюра запрашивается тем же защищённым POST с variant=preview. TelegramAdapter
выбирает готовый малый размер, встроенные байты либо небольшое изображение до
512 КиБ. Native location не выходит из коннектора. Ключи и метаданные превью
отдельны от оригинала. Отсутствие превью запоминается для версии сообщения.
Дисковый бюджет — 512 МиБ / 2048 записей, оригинал — до 32 МиБ.

В ленте IntersectionObserver запрашивает только превью возле видимой области.
Фиксированные размеры сохраняют положение сообщений при появлении изображения.
Последовательная очередь и кеш до 32 Blob ограничивают память браузера.
Оригинал открывается отдельным нажатием. PDF показывается штатным просмотрщиком
браузера в новой вкладке, текст — безопасным pre, медиа — нативными элементами.
При canShare(files) доступно системное меню; «Скачать» остаётся отдельным действием.
Прямой запуск macOS Preview.app из браузера не поддерживается.

## Последствия

Первичное заполнение занимает время, затем готовые файлы читаются с диска без
Telegram. Старые оригиналы остаются по запросу, старые миниатюры — при просмотре.
LRU может вытеснять медиа; завершённые фоновые задания не создают циклическую
перезагрузку вытесненного, повторное открытие восстанавливает файл. Текстовый архив
не удаляется. Не добавлены PDF-движок, транскодирование, сторонний медиасервис
или публичные URL файлов. Проверки доступа, роли и CSRF общие для обоих вариантов.
