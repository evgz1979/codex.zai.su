# ADR-0003: папки источника как административные закладки

Статус: принято по заданию владельца. Дата: 2026-11-07.

## Основание

Плоский каталог многочисленных Telegram-диалогов затрудняет выбор. Владелец
уже распределил чаты по папкам Telegram и запросил отдельные закладки.
Существующий единый чат и серверный список разрешений сохраняют свои роли.

## Решение

SourceAdapter может предоставить необязательный listConversationCatalog.
Общие ConversationCatalog и ConversationFolder описывают только метаданные,
имена папок и ID диалогов. У TelegramAdapter собственное преобразование правил
Telegram; MessengerCore не знает о типах InputPeer и Telegram dialog filters.

В /admin компонент ConversationPicker показывает «Все диалоги» и отдельные
закладки папок источника. Порядок папок сохраняется, закрепления идут первыми;
один диалог может входить в несколько папок. Поиск ограничен текущей папкой.
Выбор общий для всех закладок, а «Сохранить выбор» передаёт весь список ID.

## Последствия

- Членство в папке не даёт права читать или отправлять сообщения. Доступ
  по-прежнему определяется selected_conversations в SQLite.
- Закладки не являются вкладками провайдеров и не добавляются в пользовательский
  чат. Новые диалоги внутри папки автоматически не разрешаются.
- Папки читаются из Telegram при явном обновлении каталога, без изменения
  Telegram-настроек. Их состав ограничен загруженными 1000 метаданными.
- Смена папки, поиск и обновление приложения не удаляют Telegram-сессию.
  Имена папок и тексты диалогов не требуются генератору документации или ИИ.
