# Документация Z AI Messenger

Версия приложения задаётся в [package.json](../package.json) и указана в
[README модуля](../README.md). Обновлено: **2026-11-08**.
Изменение документации само по себе не объявляет выпуск приложения.

## Текущее состояние

Messenger работает на [msg.zai.su:8443](https://msg.zai.su:8443/), отдельная
[админка](https://msg.zai.su:8443/admin) управляет Telegram и разрешёнными диалогами.
В админке папки Telegram представлены закладками. Один компонент чата показывает
сообщения из SQLite; старые страницы появляются при прокрутке автоматически.
Полная история выбранных диалогов синхронизируется в фоне, новые сообщения —
событиями Telegram и автоматической сверкой. Общая лента объединяет их по времени.
В ленте показываются миниатюры. Вложения и превью выбранных чатов за последние
5 дней и все новые автоматически кешируются на сервере; старые оригиналы — по
нажатию. Фото/видео/аудио открываются в окне, PDF — во вкладке, текст — в просмотре. Пароли ролей, Telegram-сессия и выбор хранятся отдельно от кодовых релизов.

Фактические проверки выпусков и сохранённой Telegram-сессии записаны в
[протоколе](validation.md). Проверка метаданных папок не подтверждает отправку
реального сообщения или работу физического iPhone. Предыдущие результаты
протокола и журнала относятся к состоянию на дату соответствующей записи.

## Правила актуализации

- У каждого контракта одно актуальное тематическое описание; README содержит
  навигацию и запуск, а журнал — историю, без параллельных инструкций.
- При изменении поведения обновляются сценарий, API/данные, применимые правила
  безопасности, пояснение в коде и тесты.
- Справочник строится из AST без запуска приложения, чтения рабочей БД или `.local/`.
  Позиции строк, время генерации и хеши исходных файлов не сохраняются.
- Ссылка на определение использует якорь полного имени, например
  [MessengerService.send](reference/backend--core--service.md#symbol-MessengerService.send).
  Перестановка пустых строк или обычных комментариев не меняет справочник.
- Порядок генерации и проверки — в [разработке](development.md).
- Исторические результаты не становятся новой live-проверкой после редактирования
  документа. Авторизация, метаданные, история, отправка и физический iPhone имеют
  отдельные границы проверки в протоколе.
