# Telegram: подключение и разрешённые диалоги

1. Самостоятельно открыть [my.telegram.org](https://my.telegram.org), войти и
   получить api_id/api_hash в API development tools. Официальная
   [инструкция Telegram](https://core.telegram.org/api/obtaining_api_id).
2. Войти в **https://msg.zai.su:8443/admin** административным паролем.
3. «Источники → Telegram»: ввести api_id, api_hash и телефон с кодом страны.
   Нажать «Получить код». Данные передаются только по HTTPS в admin API.
4. Ввести код Telegram, затем пароль 2FA, если он запрошен. Поля очищаются после
   отправки. Код и пароль 2FA не сохраняются; не передавать их в переписку.
5. После успеха нажать «Получить список диалогов». Над таблицей появятся закладки
   ваших папок Telegram. Открыть нужную папку, отметить личные чаты, группы или
   читаемые каналы и нажать «Сохранить выбор». По умолчанию выбор пустой.
6. Войти в пользовательский чат его отдельным паролем и нажать «Обновить».

## Пароли и коды

| Значение | Где используется |
| --- | --- |
| Пароль admin | Веб-вход в /admin; задаётся в Messenger |
| Пароль chat | Веб-вход в общий чат; задаётся отдельно от admin |
| api_id и api_hash | Реквизиты одного приложения из API development tools на my.telegram.org |
| Код Telegram | Одноразовое подтверждение попытки, начатой кнопкой «Получить код» |
| Пароль 2FA | Облачный пароль двухэтапной проверки Telegram, ранее заданный владельцем аккаунта |

Пароль 2FA вводится только после запроса этого шага. Код для входа на
my.telegram.org относится к сайту Telegram и не заменяет код входа в Messenger.
Секретные значения вводятся только в соответствующие защищённые формы.

Каталог содержит до 1000 записей Telegram; поиск выполняется по загруженным
названиям. Можно разрешить до 100 диалогов. Метаданные выбора не являются
синхронизацией истории: preview отбрасывается. Секретные чаты и communities
не поддерживаются. Только отмеченные ID участвуют в чтении, отправке и отметке
прочитанного. Каналы без права записи отображаются только для чтения. Форумы
с темами и платная отправка Stars остаются без отправки в этой версии.

## Закладки папок

«Все диалоги» показывает весь загруженный каталог. Остальные закладки повторяют
названия и порядок ваших папок Telegram, включая импортированные общие папки.
Учитываются явные включения, исключения, закреплённые чаты, контакты, боты,
группы, каналы, непрочитанные, архив и отключённый звук. Закрепления идут первыми.
Один диалог может присутствовать в нескольких папках; отметка у него общая.
Поиск работает внутри текущей папки, скрытые галочки сохраняются при переключении.
«Сохранить выбор» сохраняет все отмеченные диалоги, включая другие папки.

Правила читаются через [messages.getDialogFilters](https://core.telegram.org/method/messages.getDialogFilters),
их смысл описан в [API папок Telegram](https://core.telegram.org/api/folders).
Приложение не создаёт и не меняет папки в Telegram. Чтобы получить изменения
их названий, состава или статусов чатов, нажать «Получить список диалогов» ещё раз.
При достижении лимита 1000 диалогов показано предупреждение о неполном составе.
Папка сама по себе не разрешает чтение и не включает будущие чаты автоматически.

Существующая сессия и выбор хранятся вне кодовых релизов. Обновление приложения
не требует заново вводить api_id, api_hash, телефон, код или 2FA. После рестарта
нужно лишь повторить вход в веб-админку. Telegram может отдельно отозвать сессию,
например через раздел «Устройства» официального клиента.

Снятие галочки немедленно исключает диалог из серверной ленты и будущих запросов. Открытая вкладка проверяет только разрешённые ID каждые
пять секунд и при возвращении на вкладку; скрывает исключённые диалоги без
загрузки новой истории.
Запоздалый результат текущего чтения отбрасывается по ревизии выбора. Уже
начатую отправку нельзя отозвать снятием галочки. Ранее сохранённый кеш остаётся
в SQLite и может быть виден после повторного разрешения диалога.

Вход живёт до пяти минут, в один момент активен один процесс. Поддержаны код и
2FA существующего аккаунта; email/reCAPTCHA/регистрация нового аккаунта здесь
не реализованы. Неверный код или пароль можно исправить в текущем шаге; новый
код автоматически не запрашивается. При отказе на пятой или более поздней
проверке кода/2FA процесс завершается. Остальные ошибки завершают вход сразу.
Закрытие вкладки не сохраняет код/пароль на диск.

## Если «Получить код» завершается отказом

Пустые поля api_hash и телефона после нажатия означают очистку формы, а не
потерю данных до отправки. Под статусом выводится фиксированная причина:
отклонённая пара API, неверный номер, ограничение попыток, проблема сети либо
неподдержанный способ подтверждения. Если Telegram сообщил срок ограничения,
показывается число секунд. При ограничении не запрашивать код многократно.

Причина содержит только категорию из разрешённого набора. Исходное исключение,
request, телефон, ключи и стек не выдаются и не журналируются. Неизвестный отказ
обозначается `unknown`; его нельзя трактовать как неверные ключи. Предыдущие
отказы версии 0.2.0 восстановить нельзя: подробности не сохранялись.

Код для входа на my.telegram.org отличается от кода, запрошенного Messenger.
Код сайта сам по себе не является api_id или api_hash. Ключи одного приложения
нужно взять в API development tools и вводить только в защищённой админке.

«Отключить Telegram» пытается отозвать Telegram-сессию, закрывает соединение,
удаляет локальный файл сессии и снимает выбор. Кеш не удаляется. Если сеть
недоступна, локальное отключение всё равно выполняется; удалённый отзыв нужно
проверить в официальном Telegram → Настройки → Устройства → Z AI Messenger.
Повторная авторизация использует ID источника с ID аккаунта, чтобы кеш разных
аккаунтов не смешивался.

Приложение не передаёт Telegram-тексты в Codex или другие ИИ. Автоматические
тесты используют только синтетические данные; реальный аккаунт подключает владелец.
