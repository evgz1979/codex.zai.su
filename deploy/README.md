## Будущий перенос приложения

Целевая среда: Ubuntu 24.04, Node.js 22.16+, 1 vCPU / 2 ГБ RAM.
Сборка frontend выполняется заранее, после неё один процесс Node обслуживает
статику и API и держит один дочерний Codex App Server по stdio.
Одновременно разрешён один ответ Codex. Docker, БД и платные внешние сервисы
приложению не требуются. Для ответов нужен доступ Codex к сервису моделей и
авторизованная учётная запись с доступным лимитом.

Перед будущим переносом нужно отдельно спроектировать аутентификацию веб-клиента,
TLS и безопасный удалённый доступ, ограничения ресурсов и резервное копирование.
Текущий loopback API не является публичным сервисом. Порт 443 занят Xray/VLESS
REALITY: не менять его конфигурацию и не занимать порт.

На VPS разрешён только отдельный статический тест из задания №2.
Само приложение, его systemd и аутентификация — отдельное следующее задание.
Настройки VPN не изменять.
