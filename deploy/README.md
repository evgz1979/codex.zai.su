Сборка frontend выполняется заранее, после неё один процесс Node обслуживает
статику и API и держит один дочерний Codex App Server по stdio.

приложению не требуются. Для ответов нужен доступ Codex к сервису моделей и
авторизованная учётная запись с доступным лимитом.

TLS и безопасный удалённый доступ, ограничения ресурсов и резервное копирование.

REALITY: не менять его конфигурацию и не занимать порт.
